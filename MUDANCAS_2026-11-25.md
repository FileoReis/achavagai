# AchaVagAI — correções após auditoria da versão .4

## Empregare
- O diagnóstico anterior recebia o JSON da API e o repassava ao sanitizador HTML, que removia os valores como texto e produzia arquivos praticamente vazios.
- A extração agora valida o schema documentado `model.dados` e aceita wrappers alternativos (`data`, `items`, `results`, `vagas`, `jobs`, `registros`) somente quando os registros apresentam campos de título reconhecidos.
- Quando a estrutura JSON muda, salva em `diagnosticos/json/` somente nomes de campos e tipos; nenhum valor de anúncio, e-mail ou telefone é persistido.
- Se o endpoint responder HTML, guarda somente estrutura DOM permitida (tags/classes/atributos semânticos), sem conteúdo, links, cookies ou valores.
- Distingue coleção vazia real de schema inesperado e de HTML inesperado.

## VagasRio
- A captura da versão .4 continha `body.search.search-no-results` e `section.no-results.not-found`: agora isso é classificado como busca sem resultados, não como redesign do portal.
- Corrigida a URL de busca para usar `urlencode`, evitando problemas com acentos e espaços.
- Atualizada a URL base para `https://www.vagasrio.com.br`, domínio canônico apresentado na página pública.
- Após os seletores do tema e o parser semântico, tenta uma única consulta pública à rota WordPress REST `/wp-json/wp/v2/posts` quando não há vaga relevante. O fallback pode não funcionar se o site desativar ou bloquear a rota; nesse caso o programa registra o status e continua.

## Diagnóstico compartilhado
- Registra URL solicitada e URL final após redirecionamentos; ambas são sanitizadas e não guardam query string ou fragmento.
- A chamada HTTP compartilhada não conta duas vezes um mesmo erro quando `raise_for_status()` lança `HTTPError`.
- XML é lido com `ElementTree` para inspeção; não é enviado ao parser HTML do BeautifulSoup. Isso elimina `XMLParsedAsHTMLWarning` também quando um feed XML não retorna itens.
- Páginas WordPress com marcadores `search-no-results`/`.no-results` são reconhecidas explicitamente.

## Verificação
- `python -m pytest -q`: **510 testes aprovados**.
- `python -m compileall -q .`: aprovado.
- `python main.py --help`: aprovado.
- Nenhuma requisição real foi feita à Empregare ou ao VagasRio nesta validação. O fallback do VagasRio e a resposta real da Empregare precisam ser confirmados na máquina do usuário.

## Segurança do pacote
- O pacote não inclui `.env`, currículo pessoal, histórico local, preferência de modelo, diagnósticos antigos nem caches/arquivos compilados.
- `.env.example` foi incluído; copie-o para `.env` e preencha as credenciais localmente. Não compartilhe o `.env`.
